# Player_recruitment_analysis
This repository contains the Power BI report, data assets, and presentation files for the **Player Recruitment Analytics** project. This data analytics solution evaluates football players' performance metrics to identify and suggest optimal transfer targets for team recruitment strategies.
You can explore the interactive Power BI dashboard for this project here: https://drive.google.com/drive/folders/1R1WCaZe3zfoJq27NAPRzBMSQ0aJ_rCHp?usp=sharing
